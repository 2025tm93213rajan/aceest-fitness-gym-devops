# Legacy versions

Original Tkinter desktop prototypes of ACEest Fitness & Gym, supplied with the
assignment. They are not executed by the CI/CD pipeline; the business rules
(programs, calorie factors, BMI, progress, workouts, membership) were ported
to the Flask service in `aceest/`.

| File | Highlights |
|------|-----------|
| `Aceestver-1.0.py` | Program viewer (Fat Loss / Muscle Gain / Beginner) |
| `Aceestver-1.1.py` | Client profile and calorie estimate |
| `Aceestver-2.1.2.py`, `Aceestver2.0.1.py`, `Aceestver1.1.2.py` | SQLite persistence and weekly progress (first two are identical) |
| `Aceestver-2.2.1.py` | Intermediate build |
| `Aceestver-2.2.4.py`, `Aceestver-3.0.1.py` | Workouts, metrics, BMI, charts (identical files) |
| `Aceestver-3.1.2.py` | Login, membership expiry, program generator, PDF report |
| `Aceestver-3.2.4.py` | Membership status/end date, adherence chart |
