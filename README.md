# ACEest Fitness & Gym – DevOps CI/CD Project

Flask-based fitness and gym management service with an automated CI/CD
pipeline (GitHub Actions + Jenkins) and Docker containerization.

> Work in progress – full documentation is added in the final phase.

## Repository layout

| Path | Purpose |
|------|---------|
